{% trans "Lithium Help" %}

{% trans "Quick start" %}

  1. {% trans "As an organization Admin (or owner), open" %} {% trans "Settings" %}.
    • {% trans "On the Lithium / numbering tab, set item-number digits (you can increase later, not decrease) and define part classes if you use semi-intelligent numbers." %}
    • {% trans "On Organization, review product types (Material Type) and, if you use SystemGroup import, enable it and set the CRM base URL." %}
    • {% trans "On User, set your language and — for SystemGroup import — open SystemGroup login with your personal CRM credentials." %}
  2. {% trans "Create or upload materials, then build product trees (BoMs) for assemblies." %}
    • {% trans "Use New Material and Upload materials from Home or the materials list." %}
    • {% trans "Open a product, open the Bill of Materials tab, and add subparts (or upload a CSV / Import material from SystemGroup)." %}

{% trans "Concepts" %}

{% trans "Lithium keeps your organization’s catalog of materials and how they assemble into products." %}

  • {% trans "A material (part) has a part number, description, and one or more revisions." %}
  • {% trans "Material Type (product type) classifies a revision. Types with “Has BoM” are products that can have a bill of materials; types with Has BoM off are raw materials." %}
  • {% trans "A Bill of Materials (BoM) lists the child materials (subparts) and quantity needed for a product revision." %}
  • {% trans "Working revisions can be edited; Released revisions are locked until reverted to Working." %}

{% trans "Users and roles" %}

{% trans "Each user belongs to one organization. Viewers can search and view. Admins can create, edit, upload, and delete. The organization owner manages users, organization settings, and SystemGroup import enablement." %}

{% trans "Part numbers" %}

{% trans "Choose a numbering scheme when you create the organization. Changing later is difficult once materials exist." %}

{% trans "Semi-intelligent (recommended)" %}

{% trans "Part numbers look like CCC-NNNNNN-VV: a part class code, an item number (3–10 digits, set in Settings), and a variation. Lithium can assign the next item number when you omit it." %}

{% trans "Define part classes in Settings (form or CSV). Sample file:" %} {% trans "sample part classes CSV" %}.

{% trans "Intelligent" %}

{% trans "You assign any part number string yourself. More flexible for legacy schemes; less automatic assignment." %}

{% trans "Settings" %}

  • {% trans "User" %} — {% trans "Profile, language, and a link to SystemGroup login for BoM import." %}
  • {% trans "Lithium / numbering" %} — {% trans "Part classes and item-number length (admins)." %}
  • {% trans "Organization" %} — {% trans "Name, product types, users (owner), Enable SystemGroup BoM import, and SystemGroup CRM base URL (for example http://192.168.x.x/)." %}

{% trans "Live SystemGroup import needs all three: import enabled on the organization, a CRM base URL, and your own saved CRM credentials." %}

{% trans "Home and materials" %}

{% trans "After login, Home lets you jump to a part number or open the materials list. Search by part number, description, manufacturer, or MPN. Admins can create materials, upload CSV lists, and (when permitted) import from SystemGroup." %}

{% trans "Open a material to see revisions, specifications, BoM (for products), where-used, sourcing, and customer pricing (admins)." %}

{% trans "Bill of materials" %}

{% trans "On a product revision’s BoM tab you see the indented tree: level, code, quantity, description, revision, LoI, and price. Nested products expand to show their children." %}

{% trans "Add or edit a subpart" %}

{% trans "Admins add a subpart with the material’s part number and Quantity (weight / amount for that line). Edit subpart uses the same Quantity field." %}

{% trans "Reference and Do Not Load are not shown in the add/edit subpart UI. Existing values stay unchanged when you save from that form. Those fields remain available via CSV upload if your process needs them." %}

{% trans "Upload a BoM CSV" %}

{% trans "From the BoM tab (Add all subparts) or Upload bill of materials, send a CSV. Each row needs part_number or manufacturer_part_number, plus quantity (empty defaults to 1). Optional: reference / designator, do_not_load / dnl (Y/X), revision, description." %}

{% trans "Import SystemGroup BoM" %}

{% trans "Pull a PAC Engineering BoM from the on-LAN SystemGroup CRM into Lithium. Missing parts and revisions are created; existing ones are reused." %}

{% trans "Before you import" %}

  1. {% trans "Organization owner: Settings → Organization → enable SystemGroup BoM import and set the CRM base URL." %}
  2. {% trans "Each admin who imports: open SystemGroup login (from Settings → User or when opening Import material) and sign in with your CRM credentials." %}
  3. {% trans "Open Import material from Home, or Import SystemGroup BoM from the upload menu." %}

{% trans "Preferred flow" %}

  1. {% trans "Choose Material Type for a newly created parent product. New child materials get the first product type with Has BoM off. Existing materials keep their current type." %}
  2. {% trans "Enter the CRM Part ID (left side of «کد BOM»)." %}
  3. {% trans "Click Load revisions, pick the revision, then Import this BoM." %}

{% trans "Shortcut: enter part-id/revision in the same Part ID field (for example 1155F229/A2*10-C, matching CRM «کد BOM») and click Get the BoM." %}

{% trans "If a BoM already exists" %}

{% trans "You can keep the current tree and append the import, or replace it with the CRM BoM." %}

{% trans "More options" %}

{% trans "Under More options you can paste a CRM BoM id or Edit URL, upload saved Edit HTML/JSON for offline import, browse the CRM BoM list, or run a dry run (parse only)." %}
